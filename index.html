Build a Course with the Stat Mania Template

A self-guided tour of the course template itself: learn how modules, lessons, quizzes, takeaways and progress tracking fit together, then copy it to start your own course.

SM Created by
Stat Mania, Course authoring team Last updated 10.2026

📚 What you'll learn

  • Understand how the three-column course layout maps to files and settings.
  • Create modules and lessons and put them in the right order.
  • Use front matter to drive lesson headers, time estimates and the home page.
  • Add takeaways, callouts, discussion prompts and graded quizzes.
  • Write code blocks, and know how to switch on live, executable code.
  • Customise colours and layout, then render and publish the course.

🧰 Requirements

  • A text editor and Quarto 1.4 or newer.
  • Python 3 with PyYAML (used by the pre-render script).
  • No prior Quarto experience needed.
